# 3D Print Log uploader for OrcaSlicer

An OrcaSlicer 2.5+ plugin that sends each exported or sent print to [3D Print Log](https://www.3dprintlog.com), the way the [Slic3r post-processing uploader](https://github.com/HoffmanEngineering/Slic3rPostProcessingUploader) does.

Work in progress: OrcaSlicer plugins are only in the 2.5.0 alpha so far.
